# Security policy

## Report a vulnerability

Do not open a public issue for a suspected vulnerability or include secrets,
credentials, customer content, or other sensitive details in an issue.

Private reports use GitHub private vulnerability reporting. When the
repository's Security tab shows **Report a vulnerability**, submit the report
through the [private advisory form](https://github.com/millworkdev/solver-python/security/advisories/new).
That route is controlled by a repository setting; this file does not enable it.
If the private form is unavailable, no private intake route is claimed here.
Do not disclose the details publicly.

Include the affected version, impact, reproduction steps, and any safe evidence
that helps us assess the report. Remove tokens and customer data first.

## Response and disclosure targets

After a private report is received, the targets are acknowledgement within
three business days and a severity and next-step assessment within seven
business days. We coordinate disclosure for up to 90 days. Active exploitation
or user safety may require a faster release.

These are response and coordinated-disclosure targets, not guaranteed service
levels. No additional security response SLA is promised.
